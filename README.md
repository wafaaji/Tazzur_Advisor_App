# Tazzur_Advisor_App
The Taazur Advisor App is designed to provide Consultation to both companies and users. Advisor can see the complete information about company or user and replay to their requests for consultation.

## Features
- **Comapnies Requests:** See the company request and complete information.
- **Users Requests:** See the user request and complete information.
- **Multi Languages:** Create the app with two languages (English & Arabic).
- **Notifications:** Receives notification when there is any update from the application or any new request from the companies or users.

## Technologies Used
- **Dart:** The programming language used for Flutter.
- **Flutter:** For building the mobile app.
- **RESTful APIs:** For server-side interactions.
- **GetX:** For State Managment.
- **Firebase:** For State Managment.
